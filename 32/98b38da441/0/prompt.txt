TASK T09 · W3 · Replay sandbox with no future history
GOAL: Build an isolated workspace for any commit of any repo that contains that commit's tree and nothing after it.
READ: docs/DESIGN.md §"Replay at the parent commit".
OWNS: src/sandbox/index.ts, src/sandbox/isolation.ts, tests/sandbox.test.ts
BUILD:
- createSandbox(repoPath, commitSha, {root}): `git archive <sha> | tar -x` into a fresh dir, `git init`, one base commit
  with fixed author/date; returns {path, baseSha}. Copies nothing from .git of the source.
- proveIsolation(sandboxPath, sourceRepo, commitSha): asserts (a) `git log --all` has exactly 1 commit, (b) no object in the
  sandbox store matches any blob that exists only in commits after commitSha (check a sample of ≥ 50 future blobs, or all if
  fewer), (c) no remotes and no reflog beyond base. Returns {ok, checks[]}.
- destroySandbox(path).
ACCEPTANCE: on a fixture repo (build one in the test with plain git commands), a sandbox at commit 3 of 6 passes isolation;
a deliberately leaky copy (cp -r of .git) fails it.
TEST: bun test tests/sandbox.test.ts
DO NOT TOUCH: anything outside OWNS.
